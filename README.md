# Campus Loop

A mobile-first web prototype for a closed-network peer-to-peer rental marketplace for university students.

## Features
- **Nord Dark Theme**: Custom dark theme with specific accent colors.
- **Mobile-first Design**: max-width ~420px to simulate a phone app, centered on desktop.
- **Offline Storage**: Uses `localStorage` so data survives refresh.
- **Simulated Payment**: Fake escrow and payment process.

## How to Run

1. Make sure you have Node.js installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the provided `localhost` URL in your browser.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Lucide React (Icons)
